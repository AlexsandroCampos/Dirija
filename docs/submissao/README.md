- **A empresa não pode estar constituída na data da submissão** se ela for feita como "empresa a constituir" (9 h).

## O que não é possível gerar aqui

- ORCID, Lattes e dados pessoais (CPF, endereço, datas de nascimento): só cada membro pode criar e conferir.
- Propostas comerciais reais: precisam vir dos fornecedores.
- Documentos assinados, certidões e contrato social registrado.
